# Simple Calculator

## Project Title

Simple Calculator using Python

## Description

This project is a basic calculator developed using Python.
It performs addition, subtraction, multiplication, and division
based on the user's choice.

The program also handles division by zero using try/except
and displays an appropriate error message.

## Technologies Used

- Python
- Conditional Statements
- User Input
- Try/Except Exception Handling

## Features

- Addition
- Subtraction
- Multiplication
- Division
- User-friendly menu
- Division-by-zero error handling
- Invalid choice handling

## Setup Instructions

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder.
4. Run:

```bash
python calculator.py
